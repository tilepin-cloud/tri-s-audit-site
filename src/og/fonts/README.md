# OG image fonts

Drop TTF or OTF files here to make the social-card images identical on every build machine, for example
`FiraSansCondensed-SemiBold.ttf` and `JetBrainsMono-Regular.ttf` (both SIL Open Font License, from the
Google Fonts repository). Without them resvg uses system fonts: Bahnschrift and Consolas on Windows,
DejaVu or Noto on the Cloudflare build image.
